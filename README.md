# CYRT SOON.｜擎雲順起來 AI 智能島

網站：https://ching1002.github.io/cyrt-ai-island/

12 座六角島嶼、48 個工作站與 8 位夥伴的互動 3D AI 工作模擬。

- 點人物追蹤；有案件時會跨島、坐下處理、起身交件，再返回原島。
- 人物頭上顯示案件名稱、站次與本步進度；包裹及交接弧線呈現案件流動。
- 支援全景、鳥瞰、協作路線、日夜、萬聖節裝飾及手機操作。
- 總部南瓜旁的小相機藏有照片彩蛋；模擬時鐘午夜有背景小煙火。

## 發布與更新

GitHub Pages 使用 `main` 分支的根目錄（`/`）。`index.html` 是完整成品，樣式、程式、資料與彩蛋照片均已內嵌；Three.js 0.160.0 由 HTTPS CDN 載入。

更新時，從本機專案重新建置並替換 `index.html` 後推送到 `main`。`.nojekyll` 保留靜態檔案發布方式。照片不依賴任何電腦磁碟路徑。

所有案件、分工、指標及運算點數均為展示模擬，沒有串接真實公司系統。
